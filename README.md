# MiniGoldSync

Streamline your gold management by setting up rules to automatically withdraw and deposit gold from your warband bank each time you pay it a visit.

Useful for those with multiple alts ensuring your alts have enough money for their daily purchases as well placing that hard earned cash in your central bank.

Features:

- Specify a default desired gold amount to maintain across all characters.
- Configure gold override values per character.
- Ignore specific characters from the process entirely (e.g. your main).
- Prints messages to chat when withdrawing/depositing so you know what's going on.

This is a brand new addon and features will be added over time.

Feedback and feature requests are more than welcome!
